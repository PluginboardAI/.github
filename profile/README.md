## Plug in what your agents are missing

[Pluginboard](https://pluginboard.ai) is where you find plugins, skills and MCP servers for your AI agents. Every listing is security-scanned, and every listing has install steps for each agent it works with: Claude, ChatGPT, Gemini, Claude Code, Codex, Cursor and more.

### Our lists

Each list is built from the live Pluginboard catalog and refreshed every week. Only listings whose latest security scan passed make it in.

| List | What's in it |
|---|---|
| [awesome-agent-skills](https://github.com/PluginboardAI/awesome-agent-skills) | Agent Skills: folders with a `SKILL.md` that your agent loads when they fit the task |
| [awesome-agent-plugins](https://github.com/PluginboardAI/awesome-agent-plugins) | Claude plugins, Gemini extensions, ChatGPT and Codex plugins |
| [awesome-mcp-servers](https://github.com/PluginboardAI/awesome-mcp-servers) | MCP servers that give your agents new tools, hosted or local |

### For makers

Built something for agents? [List it for free](https://pluginboard.ai/submit). Once it's live and its scan passes, it can show up in these lists on its own.
